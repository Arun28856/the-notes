📝 Notes App (MERN Stack)
📌 Overview

A Notes Application built using the MERN Stack, focusing on implementing basic CRUD operations to create, edit, and delete notes.

This project is currently in an early development stage, with authentication features planned for future releases.

🔗 Project Link: https://the-notes.onrender.com/

🚀 Features

Create notes
Edit notes
Delete notes
Clean and responsive UI

🧱 Tech Stack

MERN Stack
Vite.js (Frontend)
Tailwind CSS
DaisyUI

React Hot Toast (Notifications)

🔮 Upcoming Features
User authentication (JWT)
OAuth-based login

User-specific notes

🌐 Deployment

The application is deployed on Render.
